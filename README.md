# Money_Site

Интерактивный веб-калькулятор, который рассчитывает и отображает заработок в реальном времени, обновляя сумму каждую секунду на основе введенной почасовой или поминутной ставки.

## Описание проекта

Этот проект представляет собой легкий и наглядный инструмент для визуализации заработка. Пользователь вводит свою ставку (в час или в минуту), и скрипт начинает динамически увеличивать счетчик каждую секунду. Проект отлично демонстрирует навыки работы с таймерами (`setInterval`), манипуляциями с DOM и реактивным обновлением интерфейса на стороне клиента без перезагрузки страницы.

---

## Стек технологий

- **HTML5** — семантическая разметка страницы и формы ввода данных
- **CSS3** — стилизация интерфейса, создание визуально приятного и современного дизайна
- **JavaScript (ES6+)** — логика расчета, работа с таймерами и динамическое обновление значений на странице

## Запуск локально



1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/Money_Site.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd Money_Site
   ```
3. Откройте файл index.html двойным кликом в любом современном браузере.
